Two profiles

Two retailers, two order models, one component set. Each retailer publishes its profile as a model; what it requires is in the model's schema, read here from that schema, not from a rule set beside it. The first order of each retailer's year is written as its own UBL 2.3 Order, read into both models, and validated under each. What a model refuses is named.
